# PlaceRate - Vibrant Community Web Application

PlaceRate is a web application designed to evaluate and measure community vibrancy across multiple key dimensions. Built with React, TypeScript, and Vite, it provides interactive tools for assessing place quality, visualizing dimension scores, and exploring persona perspectives.

## Features

- 🌟 **Multi-Dimension Scoring**: Evaluates core community metrics across key dimensions.
- 🎯 **Persona Selector**: View and analyze score data tailored to specific community personas and perspectives.
- 📊 **Visual Analytics**: Interactive canvas-based Vibrancy Wheel for clear visual presentation of dimensional scores.
- ⚡ **Fast & Responsive**: Built with Vite and React 18 for high performance and smooth user experience.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/andilim1178/chc-vibrant-community.git
   cd chc-vibrant-community
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

To start the local development server:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173` (or the port specified in your terminal).

### Production Build

To build the application for production:

```bash
npm run build
```

To preview the built production app locally:

```bash
npm run preview
```

## Tech Stack

- **Frontend**: React 18, TypeScript
- **Build Tool**: Vite
- **Styling**: Modern Vanilla CSS
